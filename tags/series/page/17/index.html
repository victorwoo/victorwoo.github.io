适用于 PowerShell 5.1 及以上版本

本文将介绍三种实用的自动化文档生成方案：基于注释帮助的函数文档提取、基于 AST 的代码结构分析，以及基于 JSON Schema 的配置文档自动生成。每种方案都附带可直接运行的示例代码和输出效果。
