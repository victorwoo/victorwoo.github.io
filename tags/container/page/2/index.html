本文将介绍如何安装和配置 Kubernetes .NET 客户端，并通过三个实用场景——集群状态查询、资源批量操作和事件监控——展示 PowerShell 作为 Kubernetes 客户端的强大能力。

本文将从零开始，用 PowerShell 构建一套轻量级的微服务健康检查工具：先封装单服务探测函数，再扩展为批量并行检查，最后输出结构化的健康报告。
