# 博客文章复核

对指定的博客文章运行脚本复核和 AI 质量审查。

## 参数

- $ARGUMENTS: 文章路径或日期（如 "2025-04-16" 或 "source/_posts/2025-04-16-xxx.md"），留空则复核所有最近新增的文章

## 执行流程

### 1. 确定复核范围

- 如果参数是日期：匹配 `source/_posts/YYYY-MM-DD-*.md`
- 如果参数是路径：直接使用
- 如果留空：找出最近 7 天新增的文章（`git diff --name-only HEAD~1 source/_posts/`）

### 2. 脚本复核

对每篇文章运行：
```bash
python3 util/review-article.py --hexo source/_posts/YYYY-MM-DD-xxx.md
```

收集所有结果。

### 3. AI 质量审查

对脚本 pass 的文章，追加 AI 判断：

- **内容深度**：是否只有代码没有说明，背景引入是否有实质内容
- **技术准确性**：代码逻辑是否有明显 bug，API 用法是否正确
- **重复度**：与已有文章的角度是否有所区别
- **风格一致性**：是否符合系列文章的写作风格
- **示例质量**：执行结果示例是否合理

### 4. 输出报告

```
复核结果：
  ✅ 2025-04-16 防火墙规则管理 | 476行 | pass
  ⚠️ 2025-04-18 哈希表深度解析 | 322行 | pass_with_warnings (背景引入过短)
  ❌ 2025-04-24 文件系统监控 | 10行 | fail (行数不足, 缺少执行结果)
```

对 fail 的文章，提供具体问题清单。
